
# Bounded Coding Rules

- Make only the changes explicitly requested by the user.
- Inspect only files relevant to the current task.
- Do not refactor unrelated code.
- Do not run tests, builds, linters, type checks, or development servers unless explicitly requested.
- Do not install or update dependencies unless explicitly requested.
- Do not repeat a failed command.
- Do not repeatedly attempt alternative fixes without user approval.
- If an unexpected error occurs, explain it and stop.
- After editing, inspect the diff and summarize the changes.
- Stop when the requested change is complete.
- For small tasks, prefer editing no more than three files.
